MARGINALIA — START HERE (WINDOWS)

You do not need technical knowledge to use Marginalia.

BEFORE YOU START

- This version supports Windows 10 and Windows 11 on x64 computers.
- You need internet access during the first start.
- Marginalia never edits your original Zotero or Obsidian files.
- AI is optional. Ordinary keyword search works without Ollama or AI models.

HOW TO START

1. Download Marginalia-Windows-v0.1.0-beta.3.zip from the GitHub Release page.
   Do not download the automatically generated “Source code” archives.

2. Right-click the downloaded ZIP file and choose “Extract All”.
   Do not run Marginalia from inside the ZIP preview.

3. Open the extracted Marginalia-Windows-v0.1.0-beta.3 folder.

4. Double-click “Start Marginalia.cmd”. Keep the command window open while
   using Marginalia.

5. If Python 3.12 is already installed, Marginalia uses it. If it is missing,
   Marginalia asks whether it may install the official Python package using
   Windows Package Manager. Press Y to agree or N to cancel. Nothing is
   installed without your confirmation.

6. On the first start, wait while Marginalia prepares its private environment.
   The application then opens in your web browser.

7. Choose your Zotero data folder, your Obsidian vault, or both. Choose at
   least one source and click “Copy and build my library”. Marginalia searches
   private copies; your originals are not changed.

OPTIONAL AI

When Marginalia reaches the AI step, you can choose one of these options:

- “Skip AI · use BM25” — recommended if you only want ordinary keyword search.
- Install Qwen3 Embedding 0.6B — enables semantic search by meaning.
- Install Gemma 4 12B — additionally enables locally generated answers.

Ollama and AI models are not required. They can also be installed later from
the “AI models” button inside Marginalia.

IF SOMETHING DOES NOT OPEN

- Keep the black command window open. Closing it stops Marginalia.
- Look in that window for a line beginning with “Library app:” and open the
  displayed http://127.0.0.1 address in your browser.
- If Windows Package Manager is unavailable, install Python 3.12 manually from
  https://www.python.org/downloads/windows/ and run Start Marginalia.cmd again.
- Detailed refresh information is saved locally in refresh.log.
