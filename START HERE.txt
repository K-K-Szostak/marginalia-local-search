MARGINALIA — START HERE

Marginalia uses one transparent source package on Windows, Linux and macOS.

IMPORTANT NOTICE

Marginalia was vibe-coded: it was developed through iterative collaboration
with AI coding tools, under human direction and testing. It is experimental beta
software, provided as-is and without warranty. It may contain defects. Keep
backups of important data and use Marginalia at your own risk.

BEFORE YOU START

- You need internet access during the first start.
- Marginalia never edits your original Zotero or Obsidian files.
- AI is optional. Ordinary keyword search works without Ollama or AI models.

HOW TO START

1. Download Marginalia-v0.1.0-beta.8.zip from the GitHub Release page.
   Do not download the automatically generated “Source code” archives.

2. Extract the ZIP. Do not run Marginalia from inside the ZIP preview.

3. Open the extracted Marginalia-v0.1.0-beta.8 folder. Its top level contains
   three launchers and one “marginalia” folder with the application files.

4. Choose the launcher for your computer:

   Windows  — double-click “Start Marginalia.cmd”.
   Linux    — run “Start Marginalia.sh”. If needed, first allow it to execute.
   macOS    — double-click “Start Marginalia.command”. If Gatekeeper blocks the
              first start, Control-click it, choose Open, then confirm Open.

5. Keep the terminal window open while using Marginalia. Closing it stops the app.

6. Marginalia reuses Python 3.12 when available and creates a private .venv in
   the “marginalia” folder. Windows can offer an official Python installation
   through winget. macOS can offer Homebrew packages when Homebrew is present.
   Linux explains the Python 3.12, venv and Tk packages required from your
   distribution.

7. Wait for Marginalia to open in your web browser. Choose your Zotero data
   folder, your Obsidian vault, or both, then click “Copy and build my library”.

OCR ON LINUX AND MACOS

Windows includes a local Tesseract runtime. Linux and macOS use Tesseract from
the system PATH. OCR is needed only for scanned PDFs; ordinary text PDFs work
without it. On macOS, run “brew install tesseract”. On Linux, install the
“tesseract-ocr” package supplied by your distribution.

OPTIONAL AI

- “Skip AI · use BM25” keeps ordinary keyword search with no Ollama requirement.
- Qwen3 Embedding 0.6B enables semantic search by meaning.
- Gemma 4 12B additionally enables locally generated answers.

Ollama and models can also be installed later from “AI models” in Marginalia.

IF SOMETHING DOES NOT OPEN

- Look in the terminal for a line beginning with “Library app:” and open the
  displayed http://127.0.0.1 address in your browser.
- Python 3.12 also needs venv and Tk support. On Linux these are commonly
  separate packages such as python3.12-venv and python3-tk.
- Detailed refresh information is saved locally in marginalia/refresh.log.
