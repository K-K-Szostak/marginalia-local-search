# Corresponding source and written offer

The Windows OCR runtime distributed with Marginalia includes the following
unmodified shared libraries. Their complete corresponding source is available
at no charge from the upstream locations below:

| Distributed library | Version | License | Corresponding source |
| --- | --- | --- | --- |
| `libjbig-0.dll` | JBIG-KIT 2.1 | GPL-2.0 | https://www.cl.cam.ac.uk/~mgk25/jbigkit/download/jbigkit-2.1.tar.gz |
| `libiconv-2.dll` | GNU libiconv 1.17 | LGPL-2.1-or-later | https://ftp.gnu.org/pub/gnu/libiconv/libiconv-1.17.tar.gz |
| `libgcc_s_seh-1.dll`, `libstdc++-6.dll` | GCC 14.1 runtime | GPL-3.0-or-later with GCC Runtime Library Exception 3.1 | https://ftp.gnu.org/gnu/gcc/gcc-14.1.0/gcc-14.1.0.tar.xz |

These are upstream source archives for the component versions represented in
the bundled runtime. Marginalia does not modify these libraries.

This is also a written offer, valid for any third party until at least
11 August 2029 and for as long as Marginalia distributes the corresponding
binaries, to provide a complete machine-readable copy of the corresponding
source, including the scripts used to control compilation and installation.
Electronic delivery will be free of charge; physical delivery, if requested,
will cost no more than the actual cost of performing it. To use this offer,
open a source request at:

https://github.com/K-K-Szostak/marginalia-local-search/issues

The immediate download links above will be maintained where possible. Their
temporary or permanent unavailability does not limit this written offer.
